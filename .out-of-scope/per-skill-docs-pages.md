# A human page per skill, with no site to publish it to

Decided 2026-11-17.

## What was proposed

Mirroring `mattpocock/skills`, which gives each promoted skill a page at
`docs/<bucket>/<name>.md` with four fixed sections.

Upstream publishes those pages to a website. This repository publishes
nothing, and `README.md` with the install guide already carries what a reader
needs. Three more files with four headings each would have no reader.

## What to do instead

Keep one line per skill in the bucket `README.md`, linked to its
`SKILL.md`.
