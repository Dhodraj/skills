# One look applied before the user picks a direction

Decided 2026-11-13.

## What was proposed

Letting a skill open with a house style, so a screen gets built before anyone
chose how it should look.

Three directions exist so the choice is the user's. A default aesthetic makes
every product look like the same dashboard, and it is the thing
`references/directions.md` was written to prevent.

## What to do instead

Deal three directions taken from the product's own world, stop for a pick,
and never deal a direction with values as the default.
