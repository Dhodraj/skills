# Components that are not web page components

The main registry directory covers web page components. For other surfaces,
each site below runs its own registry. `https://www.shadcn-labs.com` lists them,
but it is not a registry itself.

| Need | Site |
|---|---|
| Terminal interface | `termcn.dev` |
| Email | `emailcn.run` |
| PDF | `pdfcn.dev` |
| Open Graph image | `ogimagecn.com` |
| Video | `framecn.dev`, `snapcn.dev` |
| Shader and WebGPU | `shadercn.run` |
| Rich text editor | `editorcn.vercel.app` |
| MCP and chat app interface | `mcpcn.dev` |
| Diagram in MDX | `mdxcn.dev` |

Read the install command and the licence on the site itself before you
recommend a component from it.
