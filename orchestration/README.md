# orchestration

Skills that keep long or parallel agent work on track.

## Model-invoked

A model-invoked skill starts on its own when the work matches its description.
You can also name it.

- [`colony-orchestrate`](colony-orchestrate/SKILL.md): split work across
  sub-agents, sessions, workers or worktrees, and keep the pieces from
  colliding.
- [`constraint-ledger`](constraint-ledger/SKILL.md): keep every constraint the
  user stated in a file that later turns read, through long runs and
  compaction.
